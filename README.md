My Python Beginnings 🚀
Welcome to my repository where I track my Python learning progress. Here are my first 3 mini-projects. All projects focus on clean code and robust input validation.

📁 Project Overview
1. Password Generator (v3.0)
Description: Cryptographically secure terminal password generator.
Key Features: Generates unpredictable passwords using secure generation methods and customized character sets.
Best Practices: Type hints, PEP 8 styling, Docstrings, .join() optimization, and defensive while loops.
Tech Stack: Python 3, secrets (secure), string.

2. Math Speed Trainer (v3.0)
Description: Terminal game that tests your mental math speed and accuracy.
Key Features: Time-tracked arithmetic challenges, instant feedback, and score tracking.
Best Practices: Type hints, PEP 8 styling, Docstrings, modular code architecture, and robust input validation.
Tech Stack: Python 3, time, random.

3. ToDo List (v3.0)
Description: A simple command-line task management application.
Key Features: Task creation and display via an interactive command-line interface.
Improvements in v3.0: Refactored from a single script into standalone functions, added type hints, docstrings, and fixed the end-of-list DASH divider alignment.
Best Practices: Code split into modular functions for better structure, PEP 8 spacing compliance, secure menu system that handles invalid choices gracefully, and data validation with .strip() to prevent blank tasks.
Tech Stack: Python 3
