My Python Beginnings 🚀
Welcome to my repository where I track my Python learning progress. Here are my first 3 mini-projects. All projects focus on clean code and robust input validation.

📁 Project Overview
1. Password Generator (v3.0)
Description: Cryptographically secure terminal password generator.
Key Features: Generates unpredictable passwords using secure generation methods and customized character sets.
Best Practices: Type hints, PEP 8 styling, Docstrings, .join() optimization, and defensive while loops.
Tech Stack: Python 3, secrets (secure), string.

2. Math Speed Trainer (v2.0)
Description: A terminal game that tests your math speed and accuracy under a time limit.
Key Features: Time-limited arithmetic challenges, score tracking, and automated difficulty scaling.
Best Practices: Nested while True loops inside a for loop for safe user input handling without resetting progress on typos.
Tech Stack: Python 3.

3. ToDo List (v2.0)
Description: A simple command-line task management application.
Key Features: Task creation, display, and deletion via an interactive command-line interface.
Best Practices: Secure menu system that handles invalid choices gracefully and data validation with .strip() to prevent blank tasks.
Tech Stack: Python 3.
